## 1. CLARIO 소개

CLARIO는 여러 사람이 함께 사용하는 **디지털 공간을 효율적으로 관리하는 웹 플랫폼**입니다.
참여자의 화면 확인, 자료 전달, 활동 관리 등을 **한곳에서** 할 수 있습니다.

## 2. 시작하기

1. CLARIO 웹사이트에 접속해 **관리자 계정(구글 로그인)** 으로 로그인합니다.
2. 새로운 관리 공간을 만듭니다.
3. 참여자에게 **접속 주소 또는 초대 코드**를 전달합니다.
4. 참여자가 접속하면 **관리자 화면**에서 확인합니다.

> 참여자는 계정 없이 초대 코드와 이름만 입력해서 입장해요.

## 3. 주요 기능

| 기능 | 설명 |
|---|---|
| 🖥 화면 모니터링 | 여러 참여자의 화면을 실시간으로 확인하고 확대합니다. |
| 👥 참여자 관리 | 참여자 목록과 접속 상태를 확인합니다. |
| 🔗 자료 전달 | URL을 통해 필요한 자료를 참여자에게 전달합니다. |
| 🔔 실시간 알림 | 공지와 자료를 알리고 확인하도록 돕습니다. |
| 🤖 AI 변화 감지 | 화면과 입력의 평소와 다른 변화를 감지해 알립니다. |
| ⏺ 화면 녹화 | 활동 화면을 기록하고 저장합니다. |
| 🎯 집중 모드 | 활동에 맞는 디지털 환경을 관리합니다. |

## 4. 사용 시 주의 사항

- 화면 모니터링과 녹화 사실을 **참여자에게 미리 안내**합니다.
- 개인정보와 녹화 자료를 **안전하게 관리**합니다.
- AI 알림은 **참고 자료**로 활용하며, **최종 판단은 관리자가 합니다.**
